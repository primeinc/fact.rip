# fact.rip - The Truth Engine for Documentation

A comprehensive platform that ensures documentation trust through AI-powered validation of citations, logic verification, and source archiving.

## Features

- **Citation Validation**: Automatically verify citations against original sources
- **Logic Verification**: Detect inconsistencies and contradictions in documentation
- **Source Archiving**: Permanently preserve original sources to prevent link rot
- **Validation Badges**: Show your commitment to information integrity

## Getting Started

### Prerequisites

- Node.js 16+
- pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/fact.rip.git
cd fact.rip

# Install dependencies
pnpm install

# Start the development server
pnpm start
```

## Development

### Available Scripts

- `pnpm start` - Start the development server
- `pnpm build` - Create a production build
- `pnpm test` - Run tests
- `pnpm lint` - Check for linting errors
- `pnpm lint:fix` - Fix linting errors
- `pnpm format` - Format code with Prettier

### Code Quality

This project uses:

- ESLint for code linting
- Prettier for code formatting
- Husky for Git hooks
- lint-staged for pre-commit validation
